Privacy Policy

My Finance Forecast is a personal financial planning and cash-flow forecasting application.

Summary: the current app stores the finance plan locally. Excel import is processed on the device. Google Drive is optional and financial data is sent to Drive only when the user explicitly requests a Drive operation.

1. Financial planning data

The app may process information entered by the user such as balances, income, expenses, one-off events, debts and payment schedules. In the current version, this finance plan is stored locally on the user's device. My Finance Forecast does not operate an application backend that receives or stores the user's finance plan.

The app does not request online-banking usernames, banking passwords, card PINs or similar authentication secrets. Users should not put such credentials in imported workbooks.

2. Excel import

When the user selects an Excel file (.xlsx or .xls), the operating-system document picker provides the selected file to the app. The workbook is read and validated on the device.

Excel import does not require a Google account and does not automatically upload the selected workbook to Google Drive or to a My Finance Forecast server.

3. Local export

When the user exports a workbook locally, the app generates the Excel file on the device. The user chooses where to save or share the file through operating-system file and sharing interfaces.

4. Optional Google Drive integration

Google Drive integration is optional. If the user explicitly connects Google Drive, My Finance Forecast requests the OAuth scope https://www.googleapis.com/auth/drive.file.

This per-file permission is used for files created or explicitly used with My Finance Forecast. The app does not request unrestricted access to the user's entire Google Drive.

Drive functionality may include creating an empty template, exporting the current finance plan to the user's own Drive, and importing compatible Google Sheets already accessible to the app. Financial plan data is sent to Google Drive only after an explicit user action. The current version does not perform automatic or background Drive synchronization.

Files stored on Google Drive are also subject to Google's terms and privacy policies.

5. Google account information

The Google authorization flow may provide basic account information necessary to display which Google account is connected and to authorize the requested Drive operations. The current version does not request offline access and does not intentionally store a long-lived Google refresh token.

6. Sharing, advertising and sale of data

My Finance Forecast does not sell user financial data. The current version does not use the user's finance plan for advertising or marketing and does not intentionally send that finance plan to analytics providers.

Exports to Google Drive or destinations selected by the user through the operating-system share/save interface are user-initiated transfers needed to provide the requested feature.

7. Security and permissions

Communication with Google APIs uses HTTPS. Google Drive authorization is limited to the per-file scope used by the optional Drive feature. Broad Android file-system access is not requested; import and export use operating-system document/storage selection interfaces.

Android automatic application backup is disabled for the current locally stored financial plan.

8. Retention and deletion

Local plan data remains on the device until the user changes or resets it, clears the application's local data, or uninstalls the application. Disconnecting Google Drive ends the active Drive connection in the app. Files previously exported to the user's Google Drive remain under the user's control and can be deleted from Google Drive.

9. Changes to this policy

If My Finance Forecast changes how Google user data or financial data is accessed, used, stored or shared, this policy and the relevant in-app disclosures will be updated before the new use is introduced.

10. Contact

For privacy or support requests, use the developer contact information published with the official My Finance Forecast application listing.
