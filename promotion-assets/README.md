# LuSor Games – Promotion Assets

Public, ready-to-use media pack for press, directories, review requests, community posts and promotional submissions.

## Structure

Each product folder contains:
- `product.json` — authoritative promotion metadata and links
- app icon / brand asset where available
- `screenshots/` — selected gameplay/app screenshots in a clean numbered order

## Products

1. Nerelune: Secrets of the Cove
2. Astral Fusion
3. Life Unwritten
4. LookTwist
5. My Finance Forecast

## Usage

Prefer these assets for promotion instead of scraping images from Google Play.

Official product information should still be checked against:
- https://lusor83.github.io/
- the Google Play link in each `product.json`
