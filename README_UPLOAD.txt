DLF Technology website screenshots package

CONTENTS
- my-finance-forecast.html
- life-unwritten.html
- looktwist.html
- astral-fusion.html
- screenshots.css
- images/... with REAL individual JPG screenshots

HOW TO USE
1. Extract this ZIP.
2. Copy ALL extracted files/folders into the root of the lusor83.github.io repository.
3. Allow overwrite for the 4 HTML files and screenshots.css.
4. Commit and push to master.
5. Wait for GitHub Pages to deploy, then hard-refresh the page.

IMPORTANT
This package uses normal relative <img src="images/..."> references.
There are NO sprites, NO collage images, NO raw.githubusercontent.com URLs.
